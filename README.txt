MERCY NDULU - PORTFOLIO DATABASE

Contents:
- database/portfolio.db : ready-to-use SQLite database
- database/schema.sql   : creates the five database tables
- database/seed.sql     : inserts Mercy's portfolio information
- database/queries.sql  : five required lab queries

Tables:
profile, skill, hobby, movie, enquiry

To recreate the database:
1. Open SQLite / DB Browser for SQLite.
2. Create or open a database named portfolio.db.
3. Run schema.sql first.
4. Run seed.sql second.
5. Run queries.sql to test the database.

Note: The source document specifies five tables (not six).
